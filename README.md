# StreamClipper

Нарізає стріми Twitch і Kick, відео YouTube або файл з комп'ютера у вертикальні кліпи 1080×1920 із субтитрами для TikTok, Reels і Shorts. Усе рахується локально на твоєму комп'ютері: без платних сервісів і ключів.

## Що вміє

- **Найкращі моменти** — шукає піки за реакцією чату, гучністю, кліпами глядачів і мовленням стрімера; моменти, де стрімер мовчить або читає донати й рекламу, відкидає
- **Підряд** — ріже все відео на частини 60–90 с по межах фраз
- **Лайв** — якщо стрім іде зараз: спершу ріже те, що вже було в ефірі, далі — в реальному часі
- **Субтитри** мовою стрімера (визначається автоматично), 4 стилі, розмір, позиція
- Вебка зверху (знаходиться автоматично), весь кадр на розмитому фоні або центр
- Додатково (усе вимкнено за замовчуванням): перевірка кандидатів перед рендером, тиха цензура мату, хук на початку, автозум на реакціях, нік стрімера, обкладинки, шумоподавлення, компіляція 16:9, пошук за словами, без повторів
- Слідкування за каналами, черга посилань, профілі стрімерів, навчання на твоїх оцінках 👍/👎
- Рендер на відеокарті (NVIDIA, Intel, AMD, Apple), тихий режим, ліміт місця на диску
- Керування з телефона по Wi‑Fi (QR-код), сповіщення, оновлення однією кнопкою
- Інтерфейс: українська, русский, English

## Запуск

1. [Завантаж ZIP](https://github.com/AAndrHlyb/StreamClipper/archive/refs/heads/main.zip) і розпакуй
2. **Windows** — двічі клікни `Start-Windows.bat`. Якщо Windows пише «Захистила ваш комп'ютер» → «Докладніше» → «Виконати однаково»
3. **Mac** — правий клік на `Start-Mac.command` → «Відкрити» → «Відкрити» (лише першого разу)

Перший запуск готує програму 3–5 хвилин (бібліотеки ~600 МБ), перша нарізка із субтитрами ще завантажить модель мовлення. Програма відкривається в браузері на `http://127.0.0.1:8765`. Чорне вікно не закривай, поки працюєш.

Кліпи зберігаються у `Відео/StreamClipper` (Windows) або `Фільми/StreamClipper` (Mac).

## Якщо щось не так

- **ffmpeg не знайдено** — Windows: `winget install Gyan.FFmpeg`, Mac: `brew install ffmpeg`
- **Немає субтитрів** — антивірус або Smart App Control заблокував бібліотеку; кліпи все одно збираються
- **Twitch/YouTube перестав відкриватися** — перезапусти програму, вона сама оновить завантажувач

Відмічай автора стріму в описі. Шрифти Montserrat, Anton, Oswald, Unbounded — SIL OFL (`fonts/OFL*.txt`).
